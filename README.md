# SG 過去問トレーナー

情報セキュリティマネジメント試験（SG）の過去問を解き、間違いを記録して復習するためのローカル Web アプリ。

問題文はこのリポジトリに持たない。IPA が公開している問題冊子 PDF を画面の左半分に表示し、
右半分で解答を入力する。アプリが持つのは**正解・分野・解説・冊子の何ページ目か**と、自分の**解答履歴とメモ**だけ。

**デモ（解答は記録されません）**: <https://claude.ai/artifact/KsdV4MQzXPqwy7mGSgvYLp>

## 動かす

問題データと PDF は生成物なのでリポジトリに入っていない。IPA から取得するところから始める。

```bash
python3 -m venv .venv
.venv/bin/pip install pypdf pyobjc-framework-Vision pyobjc-framework-Quartz
.venv/bin/python scripts/build_dataset.py   # IPA から PDF を取得し、正解を読み取る
.venv/bin/python scripts/ocr_pages.py       # 筆記年度の冊子を OCR（macOS 専用・任意）
.venv/bin/python scripts/build_dataset.py   # OCR 結果を取り込む
python3 -m http.server 8799
```

ブラウザで <http://localhost:8799> を開く。`file://` では動かない（PDF と JSON の読み込みにサーバーが要る）。

`pyobjc` は OCR のためだけに必要。OCR を省くと筆記年度のページ番号が按分による推定になる
（CBT 年度は影響なし）。その場合は `pypdf` だけでよい。

演習中はキーボードだけで進む。

| キー | 動作 |
|---|---|
| `1`〜`8` | 解答を選ぶ（ア〜ク） |
| `Z` / `X` / `C` | 自信あり / あやしい / 勘 |
| `Enter`・`Space` | 次の問題 |
| `M` | メモ入力へ |

## 入っている問題

**合計 460 問。正解はすべて IPA の解答例 PDF から機械的に読み取ったもので、推測は一つもない。**

| 年度 | 形式 | 問数 | 解説 |
|---|---|---|---|
| 平成28年度 春期・秋期 〜 令和元年度 秋期（8 回） | 筆記・午前 | 各 50 問 = 400 問 | 未 |
| 令和5・6・7・8年度 公開問題（4 回） | CBT・科目 A/B | 各 15 問 = 60 問 | 全問あり |

令和2〜4年度は IPA が問題を公開していないので入っていない。

### 分野タグは二系統ある

筆記年度の解答例には IPA 自身が分野記号（Ｔ テクノロジ系 / Ｍ マネジメント系 / Ｓ ストラテジ系）を
付けているので、そのまま使っている。ただしこの区分ではセキュリティがすべて「テクノロジ系」に入ってしまい、
400 問中 266 問が一つの箱に入る。絞り込みには粗い。

そこで CBT 公開問題 60 問には、もっと細かい区分を手で付けた。
ホーム画面ではこの二つを別の見出しで並べてあり、混ざらないようにしてある。

| 細目（CBT 公開問題） | 問数 |
|---|---|
| 情報セキュリティ管理 | 15 |
| 情報セキュリティ対策 | 13 |
| 情報セキュリティ技術 | 8 |
| 経営・企業活動 | 8 |
| 監査・サービスマネジメント | 6 |
| 法務 | 5 |
| システム・ネットワーク | 5 |

### 筆記年度の問題について

出題形式は現行の CBT（科目 A）と同じ 4 択で、論点も地続きになっている。
たとえば令和8年度 問2（JPCERT/CC の CSIRT マテリアル）は平成30年度春期 問1 とほぼ同一の問題。
8 年越しの再出題で、同じ論点が周回していることが分かる。

ただし出題から年数が経っているので、**法令や規格が改正されて現在の正解と食い違う可能性がある問題**には
「法改正注意」の印を付けてある（29 問）。判定は見出しに次の語が含まれるかどうかで機械的に行っている。

```
個人情報 / マイナンバー / 特定個人情報 / プライバシーマーク
JIS Q 27001 / JIS Q 27002 / JIS Q 15001 / GDPR / 不正競争防止法
```

印が付いた問題は、答え合わせの結果をうのみにせず、現行の規定を確認すること。

### 1 ページに複数の問題が載っている

筆記年度の冊子は 1 ページに 2〜3 問が入っている（203 ページ中 173 ページ）。
PDF をそのページで開くと別の問題が目に入るので、答える対象を取り違えやすい。
演習画面には「22 ページには 問45・問46・問47 が載っています。答えるのは 問46 です。」という
案内を出している。取り違えて記録してしまったときは、演習画面の「取り消す」か、
間違いノートの「記録を消す」で履歴を消せる。

## 解説

CBT 公開問題 60 問には全問に解説を付けてある。正解の理由だけでなく、
**誤答選択肢ひとつひとつが何の説明なのか**まで書いてある。SG は紛らわしい用語を並べる出題が多いので、
そこを潰すほうが効く。自分が選んだ選択肢の解説は画面で名指しで表示される。

筆記年度 400 問にはまだ解説がない。演習画面に「解説を頼む文面を写す」ボタンがあるので、
間違えた問題だけ、その文面を使って解説を依頼する。書いてもらった解説は
[data/annotations.json](data/annotations.json) に追記すれば、以後その問題を解くたびに表示される。

解説を先に 460 問ぶん用意しないのは、解かない問題の解説は読まれないから。
間違えた問題から順に埋めていくほうが早い。

## 仕組み

- **自信度を必ず記録する。** 解答のあとに「自信あり / あやしい / 勘」を選ぶ。
  勘で当てた正解は正解として数えず、復習キューに残す。「なんとなく当たった」を実力と誤認しないため。
- **間隔反復。** 自信をもって正解したときだけ復習間隔を 1 → 3 → 7 → 14 → 30 日と延ばす。
  間違えるか勘で当てたら 1 日に戻る。
- **誤答選択肢を覚える。** 同じ問題で同じ選択肢を 2 回以上選んだら警告する。用語の取り違えはここに出る。
- **実力値。** 統計画面では素の正答率と、勘での正解を除いた実力値を並べて出す。
  「自信あり」の正答率が低い分野は、知識が誤って定着している。

記録はブラウザの localStorage に入る。ヘッダーの「書き出し」で JSON に落とせる。

## ファイル

| パス | 中身 |
|---|---|
| `index.html` | アプリ本体。これ 1 枚で動く |
| `data/annotations.json` | **手で保守する部分。** 問題ごとの分野・見出し・解説・選択肢別の誤り理由 |
| `data/questions.json` | 生成物。正解・ページ・選択肢数に注釈を合成したもの |
| `data/pdf/` | 生成物。IPA の問題冊子の複製 |
| `scripts/build_dataset.py` | IPA から PDF を取得し、`data/questions.json` を作る |
| `scripts/ocr_pages.py` | 筆記年度の冊子を OCR し、問ごとのページと見出しを拾う（macOS 専用） |

CBT 年度の冊子にはテキスト層があるので、問ごとのページ・見出し・選択肢数・科目 A/B の判定は
`build_dataset.py` だけで取れる。筆記年度の冊子はテキスト層のないスキャン画像なので、
`ocr_pages.py` で macOS の Vision を使って読む。460 問中 459 問はページが確定し、
残り 1 問だけ前後からの推定（画面にその旨が出て、「ページを直す」で直せる）。
OCR は「問」を「間」と読み違えることがあるので、どちらの字も設問の目印として受けている。
OCR を流さない場合、筆記年度のページはすべて按分による推定になる。

### 新しい年度が公開されたら

`scripts/build_dataset.py` の `SESSIONS` に 1 行足す。IPA の
[SG・FE 公開問題](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/index.html)
の年度ページから PDF の URL を見て、ディレクトリ名とファイル接頭辞を入れる。
正解・ページ・選択肢数・科目 A/B の判定は自動で入る。分野と解説は `data/annotations.json` に手で足す。

## 公開版（ポートフォリオ用）

<https://claude.ai/artifact/KsdV4MQzXPqwy7mGSgvYLp>

`scripts/make_public.py` が `index.html` から文書タグを外して `dist/index.html` を作る。
これを問題データと PDF と一緒に Artifact として公開している。

アプリは `location.hostname` が localhost 以外なら**デモ版**として動く。

| | 手元（localhost） | 公開版 |
|---|---|---|
| 解答の記録 | localStorage に保存 | **保存しない**（`save()` が何もしない） |
| 初期データ | 自分の学習記録 | 見た目を示すためのサンプル 28 問 |
| 問題冊子の表示 | PDF を iframe で表示 | **PDF.js で該当ページを canvas に描画** |
| 書き出し／読み込み／ページを直す | あり | 非表示 |
| このアプリについて | 非表示 | ホームに表示 |

公開ビューアは PDF プラグインと `confirm` / `prompt` とダウンロードを許可しないので、
それらに依存する機能は公開版では差し替えるか隠している。

更新するときは次の順で実行する。

```bash
python3 scripts/make_public.py
# dist/index.html を Artifact に再公開
```
